# Dream the Muse — Capacitor iOS

Это исходный проект, не IPA и не выполненная сборка. Серверные файлы в корне репозитория не изменяются.

## Подготовка

На macOS с Xcode 26+ и Node.js 22+: перейдите в mobile, выполните npm install, npm run ios:add, npm run ios:sync, npm run ios:open. Нативная папка ios создаётся командой cap add ios; в этом коммите её нет. После первой установки сохраните package-lock.json для воспроизводимых сборок. Для запуска на iPhone нужна настройка signing в Xcode. С iPhone без Mac используйте отдельную облачную macOS-сборку; она здесь не настроена.

## API

В интерфейсе укажите полный HTTPS endpoint вида https://YOUR-SERVICE.onrender.com/api/chat. Этот пример не является работающим адресом. URL хранится в localStorage, код доступа — только в памяти страницы. API-ключ OpenRouter вводится только на сервере. Не используйте опубликованные в чатах токены.

На сервере добавьте capacitor://localhost в ALLOWED_ORIGINS. OPTIONS обрабатывается до проверки токена; POST проверяет CHAT_ACCESS_TOKEN. Заголовки Access-Control-Allow-* возвращает сервер, не Capacitor. CORS не заменяет авторизацию.

Лимиты клиента соответствуют существующему api/chat.js: 17 сообщений, 4000 символов в сообщении, 20000 суммарно, JSON до 40000 UTF-8 байт. Старые пары удаляются при превышении бюджета. Ответ длиннее 4000 символов отображается, но контекст после него сбрасывается. История не сохраняется при перезапуске.

www/index.html содержит весь интерфейс без внешних CSS/JS. Бэкенд внутрь приложения не копируется. Сервер и OpenRouter требуют сети.
